Requirements
------------
1. Node.js 20 LTS or newer
2. MongoDB Atlas database
3. VS Code
4. Internet connection for the first npm install

BACKEND (Terminal 1)
--------------------
cd backend
copy .env.example .env

Open backend/.env and replace at minimum:
- MONGODB_URI
- JWT_ACCESS_SECRET
- JWT_REFRESH_SECRET
- ADMIN_PASSWORD
- ADMIN_SEED_KEY
- NOTIFICATION_EMAIL (default: dronebangladesh567@gmail.com)
- EMAIL_API_KEY and EMAIL_FROM for stock-out/restock/pre-order emails

Optional for cloud image hosting:
- CLOUDINARY_CLOUD_NAME
- CLOUDINARY_API_KEY
- CLOUDINARY_API_SECRET

Then run:
npm install
npm run seed
npm run dev

Backend API: http://localhost:5000/api/v1

IMPORTANT
---------
- Keep frontend on port 3000 and backend on port 5000 for this local setup.
- Run `npm run seed` after configuring MongoDB.
- Courier Delivery is the only checkout delivery method and the website delivery charge is ৳150.
- Email verification is intentionally not included.
- Stock-out products automatically show a Pre-Order action. The pre-order form
  collects name, email, mobile, address and full/partial payment preference.
- Admin > Pre-Orders manages advance bookings. When inventory returns above zero,
  active booking customers receive a restock email.
- Admin > Authenticity & Warranty manages serial records. Customers can verify
  a serial at /authenticity-checker.
- Rotate any MongoDB/JWT/Admin/Cloudinary credentials previously visible in screenshots before production deployment.
- For live SEO, replace NEXT_PUBLIC_SITE_URL with the real HTTPS domain before `npm run build`, then submit /sitemap.xml to Google Search Console.

LATEST v5 UPDATES
-----------------
- Admin Media/Cloudinary timeout is now fail-safe. Media listing falls back to local uploads instead of breaking Categories/Products with 499/500 errors.
- Added `/api/v1/admin/media/folder-categories` for fast folder metadata without a Cloudinary network call.
- Cloudinary upload failures automatically fall back to the backend local uploads folder.
- Homepage multi-banner reference design is preserved but the hero is now more compact (about 395px desktop height).
- Drones and Handhelds now use the same wide visual mega-menu design system as Enterprise & Agriculture.
- Products Management now has Navigation Mega-Menu Placement fields for Drones, Handhelds and Enterprise & Agriculture.
- Admin-created products can be assigned to a mega-menu group/column and order; storefront menus read these placements dynamically from backend product data.
- Drones/Handhelds/Enterprise CMS menu tabs still support visual groups and lower promotional cards, so content and products can both be managed without code edits.

USING MEGA-MENU PRODUCT PLACEMENT
---------------------------------
Admin > Products > Add/Edit Product > Navigation mega-menu placement
- Drones: enter a Group / column such as `DJI Mini`
- Handhelds: enter a Group / column such as `DJI Osmo Series`
- Enterprise & Agriculture: enter a Group / column such as `AGRAS`
- Set Menu order to control ordering.
- Leave a group blank if the product should not appear in that menu.

For large lower-row promotional cards use:
Admin > Drones mega menu / Handhelds mega menu / Enterprise & Agriculture mega menu
and choose Display type = Promo.
